# 🦖 DINO NEÓN

El jueguito del dinosaurio de Chrome (el de "sin internet"), pero en versión **synthwave de colores**.

🎮 **Jugar:** https://matias20090714-sys.github.io/dino-neon/

No hace falta instalar nada ni tener internet después de cargar la página: es un solo archivo HTML.

## Controles

| Acción | Teclado | Móvil |
| --- | --- | --- |
| Saltar | `Espacio` / `↑` / `W` | tocar la pantalla o botón SALTAR |
| Doble salto | pulsar saltar otra vez en el aire | igual |
| Agacharse | `↓` / `S` | botón AGACHARSE |
| Pausa | `P` / `Esc` | botón ⏸ |
| Sonido | `M` | botón 🔊 |
| Reiniciar | `R` | botón OTRA VEZ |

## Qué tiene

- Cielo que cambia de color según tu puntuación, sol retro, montañas en parallax y estrellas
- Tres obstáculos: cactús, pterodáctilos y cristales
- Power-ups: **escudo** (aguanta un golpe) y **modo estrella** (5 s invencible)
- Doble salto y caída rápida
- Partículas, sacudida de pantalla y sonidos generados con WebAudio
- Récord guardado en el navegador
- Funciona en móvil y en escritorio

## Correr en local

Descarga `index.html` y ábrelo con doble clic, o sirve la carpeta:

```bash
npx serve .
```
